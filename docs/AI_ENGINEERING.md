# AI engineering

This is a contributor and maintainer workflow document for AI-assisted changes in this repository.

Use AI assistance to accelerate implementation, not to weaken repo discipline.

Expectations:
- read the canonical docs before changing behavior
- keep plans decision-complete before non-trivial work
- prefer small, reviewable changes over broad speculative refactors
- treat public package surface changes as high-review changes
- do not introduce private-infra assumptions into the shared runtime
- do not leave model, tool, or agent signatures in source or package-facing docs
- when adding comments or examples, optimize for one consistent repo voice rather than tool-specific phrasing
